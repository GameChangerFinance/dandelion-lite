102.4 I know how to install using Windows

This module will teach you how to install and run dandelion-lite on Windows using WSL2 with the Debian distribution.

1. Install and setup Windows Subsystem for Linux

First, open powershell and update and install WSL2:

wsl --update
wsl --install Debian

For more detailed information see https://learn.microsoft.com/en-us/windows/wsl/install.

Once this has completed, the WSL configurations need to be changed. By default WSL will use half the available RAM, here we will tell it to use 60GB as well as to use the mirrored networking mode. In your user directory

C:\Users\<Username>

open or create the file .wslconfig and add the following:

[wsl2]
memory = 60G
networkingMode=mirrored

By design, WSL will terminate when not in active use. Therefore we will use

to keep WSL running. Finally, start WSL with 

wsl

2. Install dandelion-lite

Before installing dandelion-lite, install gum with

sudo apt install gum

and then follow the instructions at https://github.com/GameChangerFinance/dandelion-lite?tab=readme-ov-file#deployment to install dandelion-lite, but do not start dandoman.sh yet.

In /etc/containers/containers.conf put the following

[network]
firewall_driver="iptables"

as podman does not support nftables.

3. Setup networking

To expose haproxy to the public, forward port 443 on your router to <someport> on your Windows machine. Then proxy <someport> to port 3080 (3081 for pre-prod) using the following command:

netsh interface portproxy add v4tov4 listenport=<someport> listenaddress=0.0.0.0 connectport=3080 connectaddress=127.0.1.1

If successfull, 

netsh interface portproxy show all

should show



Listen on ipv4:             Connect to ipv4:

Address         Port        Address         Port
--------------- ----------  --------------- ----------
0.0.0.0         <someport>  127.0.1.1       3080

Finally, create an SSL certificate for the domain haproxy is located at. A simple method is to use certbot and LetsEncrypt. Follow the instructions at https://certbot.eff.org/instructions?ws=haproxy&os=pip. This will require port 80 to be forwarded and open.

Once done, concatenate fullchain.pem and privkey.pem in /etc/letsencrypt/live/$DOMAIN/, stage the combined file as dandolite/configs/ssl/server.pem, then rotate it into dandolite/secrets/ssl/server.pem for HAProxy.
