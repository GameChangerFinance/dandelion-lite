## Origins and thanks

Dandelion Lite extends the wider Dandelion vision, created by **Roberto Morano**, Gimbalabs co-founder and friend of the project. It draws on Koios Lite and many independent Cardano projects and upstream contributors. Thank you to the Dandelion community, Gimbalabs, Koios contributors, service authors, testers, documentation contributors, node operators and everyone who has helped make Cardano APIs more independently deployable.

The complete, current record of direct repository contributions is available in [GitHub contributors](https://github.com/GameChangerFinance/dandelion-lite/graphs/contributors) and [commit history](https://github.com/GameChangerFinance/dandelion-lite/commits/main/). These links recognize contributors without risking an incomplete manually maintained roster. Git history and upstream license/attribution notices remain authoritative for individual changes.

## Becoming a maintainer

There is no automatic promotion threshold. Contributors interested in sustained maintenance can discuss responsibility for a specific component in GitHub or the [community Discord](https://discord.gg/vpbfyRaDKG). Review and release permissions are granted deliberately based on trust, continuity, production judgment and availability.
